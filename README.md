# 빨간벽돌 집짓기 경매

희소성과 선택을 경험하는 교실 경매 앱입니다. 서버나 회원가입 없이 브라우저에 학급별 진행 상황을 저장합니다.

## 실행

이 폴더에서 다음 명령을 실행하고 [앱 열기](http://127.0.0.1:8873/)로 접속합니다.

```sh
python3 -m http.server 8873 --bind 127.0.0.1
```

정적 호스팅에서는 `index.html`, `style.css`, `auction-state.js`, `app.js`, `favicon.svg`를 함께 제공합니다. 빌드나 패키지 설치는 필요하지 않습니다.

## 수업 진행

1. **수업 준비**는 **새 방 만들기**와 **저장된 방 들어가기**로 나뉩니다. 새 방 만들기를 누르면 모달에서 방 이름, 팀 수(2~10팀), 재료 수량을 설정하고 **방 만들고 입장**을 누르면 브라우저에 저장됩니다. 저장된 방은 목록의 **들어가기**로 엽니다.
2. **경매**에서 판매 수량과 묶음 입찰가를 조절하고, **팀 버튼을 누르면 즉시 낙찰**됩니다. 잔액에서는 묶음 총액이 한 번 차감됩니다. **직전 낙찰 취소**는 금액과 수량을 함께 복구합니다.
3. **학생 화면 열기**는 새 탭을 열고, 교사 창의 재료·수량·입찰가·낙찰·취소를 실시간으로 반영합니다. 탭을 별도 창으로 옮겨 다른 화면에 띄울 수 있습니다. 학생 창에서는 재료·수량·입찰가를 크게 보여줍니다. 낙찰하면 학생 화면 중앙에 팀·재료·수량·총액 팝업을 2.6초 동안 표시합니다. 재료가 매진되면 낙찰 팝업이 끝난 뒤 다음 재료 소개를 시작합니다. 처음 열거나 재료가 바뀌면 재료 소개 모션이 약 2.4초 동안 나온 뒤 경매 화면으로 전환됩니다. 가격·수량 변경으로는 소개 모션을 반복하지 않으며, 전환 중에도 최신 상태를 받아 이어서 표시합니다. 모든 팀을 표시하며 예산을 모두 쓴 팀에만 **잔액 소진**을 붙입니다. 교사용 재고·잔액 숫자·집짓기 현황은 숨깁니다.
4. **결과**에서 장당 낙찰 단가(묶음 총액 ÷ 판매 수량), 남은 어스 순위, 집짓기 결과, 집을 완성한 최저 지출 팀, 팀별 구매 내역을 확인합니다. 잔액이 같으면 공동 순위로 표시합니다. 단가는 소수 둘째 자리까지 표시하며 그래프 좌표는 반올림 전 값을 사용합니다.
5. **회고**는 재료별 질문과 해당 재료의 실제 낙찰 단가 차트를 한 장씩 보여줍니다. **이전 질문 / 다음 질문**으로 7개 질문을 넘겨 봅니다. 회고는 화면 높이에 맞춰 질문 아래 남은 공간에 차트를 배치합니다(높이 600px 이상). 차트는 결과 화면과 같은 장당 단가 계산을 쓰며, 기록이 없으면 낙찰 기록 없음으로 표시합니다. 빨간 벽돌의 구매 수량, 철근의 구매 시점, 파란 벽돌의 희귀성과 희소성, 시멘트의 수량·수요와 가격, 우레탄의 묶음 단가, 나무합판의 부족과 전략을 돌아보고, 마지막에 우리 팀의 선택과 기회비용을 이야기합니다.

상단 **수업 출처 ↗**는 찬정샘의 Padlet 자료를 새 탭으로 엽니다. **수업 안내**에도 같은 링크와 진행 방법, 관찰 포인트, 핵심 질문이 있습니다.

## 저장과 복구

- 학급별 자동저장은 기존 `auction_class_save_학급이름` 형식을 유지합니다. 이전 버전의 잔액·재료·낙찰 기록도 불러옵니다.
- 같은 이름의 방을 다시 만들거나 저장된 방을 삭제할 때 확인합니다. 읽을 수 없는 기록은 자동으로 덮어쓰거나 삭제하지 않습니다.
- 저장에 실패하면 오류와 **다시 저장** 버튼을 표시하고 창을 닫기 전에 경고합니다.
- 기록은 같은 브라우저와 같은 사이트 주소에 저장됩니다. 다른 기기·브라우저·호스팅 주소로 자동 전송되지 않습니다.
- 학생 창은 같은 브라우저·같은 사이트의 교사 창과 동기화됩니다. 학생 창 새로고침 시 현재 방의 저장 기록을 복구하며, 교사 창에서 방을 바꾸면 학생 창도 따라갑니다. 별도 기기·다른 브라우저 연결은 포함하지 않습니다.

`mockup/`은 화면 검토용 예시이며, 실제 수업은 루트의 `index.html`에서 시작합니다.

## 검증

Node.js에서 추가 패키지 없이 실행합니다.

```sh
node --test tests/*.test.cjs
```

설정 검증, 묶음 판매와 취소, 잔액·재고 제한, 기존 저장 데이터 복구, 저장 형식 왕복을 확인합니다.
